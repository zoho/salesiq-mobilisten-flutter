## Mobilisten Core Plugin Changelog

### 1.0.0-beta.1 - 02 Sep 2026

- Major version bump aligning the core package with the 7.0.0-beta.1 Mobilisten release.
- Added the shared conversation model (`SalesIQConversation` with `Chat`/`Call` and `Media`), auth types (`SalesIQAuth`, `SalesIQUser`, `SalesIQGuestUser`), font configuration (`SalesIQFont`, `SalesIQFontType`), and `SalesIQConfiguration` session/theme options.
- Centralised the `SalesIQConversation`-to-map serialization (`getConversationMap`) shared by the mobilisten and calls plugins.


### 0.0.4 - 17 Feb 2026

- Updated Android core library to v0.0.3

### 0.0.3 - 24 Nov 2025

- Updated functions and pubspec.yaml.

### 0.0.2 - 28 Aug 2025

- Updated pubspec.yaml and README.md files.

### 0.0.1 - 28 Aug 2025

- Initial release of the plugin for the Android and iOS platforms.
